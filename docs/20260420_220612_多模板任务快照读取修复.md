# 多模板任务快照读取修复

- 时间：2026-04-20 22:06:12
- 问题：同一任务存在多个 `task_config_snapshots` 记录时，处理链路读取到了旧快照，导致多模板任务实际按旧规则执行，出现“输出视频未插入新模板素材”。

## 修复内容
- 文件：`backend/app/services/task_service.py`
- 方法：`load_or_create_task_snapshot`
- 变更：由“默认 first”改为按 `id` 倒序取最新快照：
  - `order_by(TaskConfigSnapshot.id.desc()).first()`

## 影响
- 任务处理会稳定使用最新任务配置快照。
- 已创建但未生效的多模板任务，重试后即可按最新快照执行。
