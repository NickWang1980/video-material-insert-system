# 20260423_122758 角色ASR匹配对比弹窗（项目+角色聚合分页）

## 本次实现
- 新增混剪对比接口 GET /api/rough-cut/projects/{project_id}/compare。
- 角色ASR完成（running -> completed）后，自动弹出“ASR匹配对比中心”弹窗。
- 弹窗采用两级分页：项目一级Tab + 角色二级Tab。
- 对比内容为主文本与ASR文本双栏展示，按LCS命中字符高亮。
- 弹窗内展示统计：matchedChars / srtTotalChars / matchPercent / gatePassed / asrStatus / asrProgress / asrError。
- 保留并对齐95%门槛策略，弹窗统计与按钮可用状态一致。

## 影响范围
- 后端：混剪API与混剪服务新增对比聚合能力。
- 前端：RoughCutMultiRole 新增自动弹窗、分页、高亮渲染与懒加载比较数据。
- 文档：API接口文档补充 compare 接口。

## 重启说明
- 后端需要重启（新增接口与服务逻辑）。
- 前端开发服务需要重启；生产态需要重新 build。
