# 20260509_160000_cublas_dll_fix.md

## 问题描述

运行 ASR 时出现错误：
```
Library cublas64_12.dll is not found or cannot be loaded
```

**根本原因**：`ctranslate2.get_cuda_device_count()` 只检测 CUDA 设备是否存在，但不检查 CUDA 运行时库（DLL）是否真的可以加载。在 Windows 上，即使 NVIDIA 驱动和 CUDA 编译器安装正确，如果 CUDA runtime DLL 不在 PATH 中或版本不匹配，`WhisperModel` 使用 CUDA 模式时会崩溃。

---

## 修复内容

### 1. asr_service.py — CUDA 不可用时抛出错误（不回退 CPU）

修改 `_resolve_device_compute()` 函数逻辑：

- **int8**：始终使用 CPU（不需要 CUDA）
- **float16 / float32**：**必须使用 CUDA**，如果 CUDA 不可用或 DLL 缺失，抛出 `RuntimeError` 终止进程
- **auto**：有 CUDA 用 float16，无 CUDA 用 int8

```python
if pref in ("float16", "float32"):
    if not has_cuda:
        raise RuntimeError(
            f"ASR 精度设置为 {pref}，但未检测到 CUDA 设备。"
            "请确保已安装 NVIDIA GPU 驱动，或在设置中将 ASR 精度改为 int8。"
        )
    if not _check_cuda_dlls():
        raise RuntimeError(
            f"ASR 精度设置为 {pref}，但 CUDA 运行时库 (cublas64_12.dll 等) 无法加载。"
            "请运行 precheck.sh 下载 CUDA 运行时库，或安装 CUDA Toolkit，"
            "或在设置中将 ASR 精度改为 int8。"
        )
```

### 2. asr_service.py — 添加 DLL 搜索路径

修改 `_check_cuda_dlls()` 函数：
- 添加 `os.add_dll_directory(cuda_dll_dir)` 让 Python 可以找到下载的 DLL
- 自动搜索 `tools/cuda/bin` 目录
- 添加详细日志帮助诊断问题

### 3. asr_service.py — 添加详细日志

在 `_detect_cuda_available()` 和 `_resolve_device_compute()` 中添加详细日志：
- `ASR CUDA device count: X, available: true/false`
- `Resolving device/compute: pref=float16, has_cuda=true`
- `CUDA DLL not loadable: cublas64_12.dll - [错误信息]`

## 验证方法

1. 在设置中选择 `float16` 精度
2. 如果 CUDA 不可用，应该看到错误提示：
   ```
   ASR 精度设置为 float16，但未检测到 CUDA 设备。
   请确保已安装 NVIDIA GPU 驱动，或在设置中将 ASR 精度改为 int8。
   ```
3. 如果 CUDA DLL 缺失，应该看到错误提示：
   ```
   ASR 精度设置为 float16，但 CUDA 运行时库 (cublas64_12.dll 等) 无法加载。
   请运行 precheck.sh 下载 CUDA 运行时库，或安装 CUDA Toolkit，
   或在设置中将 ASR 精度改为 int8。
   ```
