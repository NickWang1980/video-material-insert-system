# 变更记录：匹配阈值下调至80% + 对比页手动通过

## 变更目标
- 将混剪放行匹配阈值从 95% 下调到 80%。
- 在“匹配对比中心”支持对单个素材手动通过/取消手动通过。

## 后端变更
- 混剪匹配阈值统一改为 `80%`（门槛判断与进度计算同步更新）。
- 素材新增 `manualGatePassed` 属性，并参与 `gatePassed` 计算：
  - `effectiveGate = (matchPercent >= 80) OR manualGatePassed`
  - 仍要求素材 ASR 完成后才可整体放行。
- 新增接口：
  - `PATCH /api/rough-cut/projects/{project_id}/assets/{asset_id}/manual-gate`
  - 请求体：`{ "manualPassed": true|false }`
- 导出拦截文案更新为 80% 口径。

## 前端变更
- 匹配对比弹窗文案改为 80% 门槛。
- 在素材级对比区新增“手动通过/取消手动通过”按钮。
- 手动通过后实时刷新项目状态与对比数据，立即影响“一键混剪”可用性。
- 相关告警文案改为 80% 口径，并提示可在对比页手动通过。
