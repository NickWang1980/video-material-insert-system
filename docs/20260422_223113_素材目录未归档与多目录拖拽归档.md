# 素材目录“未归档 + 多目录归档 + 拖拽归档”实施记录

## 本次目标
- 增加“未归档”目录。
- 支持素材在目录树之间拖拽归档。
- 素材目录/子目录作为素材属性持久化，并支持同一素材归档到多个子目录。

## 数据与模型
- 新增表 `material_folder_bindings`：记录素材与脚本子目录的多对多关系。
- 保留 `materials` 主体属性（文件名、类型、路径、音轨状态等），并补充目录链接输出。
- 启动迁移自动把历史 `materials.script_folder_id` 回填到 `material_folder_bindings`。

## 后端能力
- 目录树接口返回新增“未归档”根节点。
- 新增素材归档接口：
  - `POST /api/materials/{id}/file`（归档到定量素材/未归档/脚本子目录）
  - `DELETE /api/materials/{id}/folders/{script_folder_id}`（从某脚本子目录移出）
- `GET /api/materials` 支持按脚本目录过滤，并按多对多归档关系返回素材。
- 素材响应新增 `folder_links[]`，可展示素材归档到的所有子目录。

## 前端交互
- 素材库改为“目录树 + 素材区”结构，目录树含：定量素材、未归档、产品目录树。
- 素材卡片和列表支持拖拽到目录树节点完成归档。
- 在脚本子目录视图中新增“移出当前目录”操作。
- 上传支持直接上传到“定量素材/未归档/脚本子目录”。

## 模板与匹配
- 模板编辑器继续使用目录字段：`素材库分类/产品目录/脚本子文件夹`。
- 素材下拉按目录上下文过滤时，改为基于 `folder_links` 判断，支持多目录归档素材。

## 兼容性
- 旧数据可继续使用；历史目录关系在启动迁移时自动回填。
- 旧模板缺失目录字段时，默认按“定量素材”处理。
