# 混剪单元：ASR时长显示与首次手动生成预览修复

- 时间：2026-04-24 11:52:52
- 范围：`backend/app/services/rough_cut_service.py`、`frontend/src/views/RoughCutUnit.vue`

## 本次改动
1. 分镜头句子的 `estimatedDuration` 在生成时间线后统一回写为实际取材片段时长：
   - 命中 ASR 时写回 `sourceEnd - sourceStart`
   - fallback 取材时也写回真实截取秒数
2. 自动调度从“自动生成时间线 + 自动生成预览”改为“仅自动生成时间线”，首次预览必须由页面按钮手动触发。
3. `混剪单元` 预览按钮改为动态文案：
   - 无预览时：`生成预览视频`
   - 已有预览时：`重新生成预览`
4. 预览状态提示改为手动触发口径：`时间线已就绪，点击生成预览`。

## 影响
- 需要重启后端。
- 若走 `8000` 生产口，需要重新 build 前端后再重启后端。
