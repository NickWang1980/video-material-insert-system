# 日志查看器模块

## 改动摘要

新增「日志查看器」页面（`/logs`），统一查看 4 类日志，支持 tail / 自动刷新 / 复制 / 下载完整文件。

| 标签页 | 来源 | 标识 |
|---|---|---|
| ASR | `data/outputs/logs/asr_*.log`（loguru，10MB 轮转） | 文件名 |
| 任务（FFmpeg）| `data/outputs/logs/task_<id>.txt` | 文件名 |
| 系统 | `data/outputs/logs/app_*.log`（**本次新增**） | 文件名 |
| 混剪 | DB `RoughCutProject.log_text` | project_id |

## UI 行为

- 左栏：按 mtime 倒序的日志条目列表，点击切换。
- 右栏：黑底浅字 tail 视图，默认末尾 1000 行，可调 100~100000；右上角操作：行数 / 自动刷新（2s 轮询）/ 手动刷新 / 复制 / 下载完整。
- 切换 tab 时自动加载对应 items；切换 item 时自动 tail 最新内容并滚到底。

## 技术要点

- **流式 tail**：`collections.deque(maxlen=N)`，O(N) 内存，可处理 GB 级文件。
- **路径穿越防护**：`_resolve_file_path` 用 `Path.resolve()` + `relative_to()` 校验在 `data/outputs/logs` 下，且必须 match 该类别 glob。
- **下载鉴权**：用 `withAuthToken(url)` 给 `<a download>` 加 `?token=`，匹配现有 auth middleware 的 GET 兼容路径。
- **新增系统日志 sink**：`logger.add(app_*.log, filter="非 asr_service")` —— 之前 stderr-only。

## 是否需要重启 / build

**需要：重启后端 + 前端热更新自动生效**

```bash
./scripts/stop_all.sh && ./scripts/start_all.sh
```

后端注册了新 router、加了新 logger sink，必须重启 uvicorn。前端只动 `.js` / `.vue`，Vite 自动热更新。
