# 2026-04-22 23:59:00 字幕识别列呼吸进度条与百分比

## 目标
- 在“源视频库”页面的“字幕识别”列显示 ASR 进度条与百分比。
- 处理中状态增加呼吸动画，提升可感知性。

## 实施内容
- 后端新增并持久化字段：`source_video_entries.asr_progress`（0-100）。
- ASR流程按阶段写入进度：
  - `running` 起始：35
  - 音频检查后：45
  - 识别完成：75
  - 写SRT后：90
  - 完成：100
  - 失败/超上限：100（异常态）
- 前端在“字幕识别”列新增 `el-progress`，显示百分比文本。
- `pending/running` 状态启用呼吸动画样式，`completed/failed` 使用正常状态色。
