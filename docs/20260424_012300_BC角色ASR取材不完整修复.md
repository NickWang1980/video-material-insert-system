# B/C角色 ASR 取材不完整修复

## 变更时间
- 2026-04-24 01:23:00

## 问题
- 角色 B/C 的 ASR 已完成，但混剪时间线中部分句子只截取到不完整片段，或落到结果视频时出现片段偏短。

## 原因
- 句子匹配算法只在游标后较小窗口内搜索，且对短窗口的精确率偏好较高，导致长句被“部分匹配”命中。

## 修复
- 将句子级 ASR 匹配从小范围窗口改为从游标到结尾的完整扫描。
- 提升“句子覆盖率”权重，降低“短窗口精确率”主导效应。
- 提高命中阈值，低覆盖匹配不再误判为命中。
- 保持连续片段窗口匹配与游标推进机制，避免重复消费同一素材片段。

## 影响
- 混剪时间线中 `sourceStart/sourceEnd/duration` 更接近角色视频里该句完整口播时段。
- 未达到覆盖阈值的句子会回退 fallback 取材，不再用低质量 ASR 半匹配。
