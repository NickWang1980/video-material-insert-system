# 2026-04-22 变更记录：素材库预览、视频去音轨、模板视频裁剪参数

## 本次目标
- 修复素材库视频预览不可看问题。
- 素材上传时，视频自动去掉音轨。
- 素材库新增 3 种展示模式：当前方式、Thumbnail、Detail List。
- 模板新增短视频参数：`视频起始秒(秒)`、`视频持续秒(秒)`。

## 已完成改动
- 后端 `materials` 上传接口：
  - 视频素材上传改为先落临时文件，再执行 FFmpeg 去音轨生成最终文件。
  - 去音轨成功后入库，`materials.audio_removed=true`。
  - 去音轨失败则该文件上传失败并返回原因。
- 后端素材预览接口：
  - 预览响应改为 inline，支持浏览器直接播放视频/音频。
- 数据模型与兼容迁移：
  - `materials` 表新增可空字段 `audio_removed`。
  - 启动时自动补列（SQLite 兼容迁移逻辑）。
- 素材库页面：
  - 增加展示模式切换（3 模式）。
  - 增加统一“预览”弹窗（图片/GIF/视频/音频）。
  - 视频素材显示音轨状态（已去音轨/保留音轨）。
- 模板配置链路：
  - CSV 导入导出新增字段：`视频起始秒(秒)`、`视频持续秒(秒)`。
  - 模板编辑器新增上述两列（仅短视频可编辑）。
  - 任务匹配事件新增字段并传递到 FFmpeg 合成层。
- FFmpeg 合成：
  - 短视频叠加支持从指定起始秒裁剪并按持续秒播放。
  - 未配置 `视频持续秒(秒)` 时，默认使用该事件的叠加时长。

## 影响范围
- 后端：素材上传/预览、模板 CSV 解析、素材匹配、视频合成。
- 前端：素材库页面、模板编辑页。

## 备注
- 本次未改动任务 API 路径与任务状态机。
- 历史模板缺少新字段时，自动使用默认值（起始秒=0，持续秒为空）。
