# 源视频条目 SRT 可选变更记录
- 时间：2026-04-21 13:18:07
- 变更目标：新建源视频条目时，SRT 非必填；未上传时提示将启动模型识别字幕；ASR 输出字幕文件名与条目名一致。

- ackend/app/api/source_videos.py
  - POST /api/source-videos 中 subtitle 改为可选。
  - 未上传 SRT 时继续创建条目并启动 ASR。
  - 新增/返回 has_uploaded_srt 状态。
- ackend/app/services/task_service.py
  - 创建任务时，subtitle_source=uploaded 增加“必须存在上传SRT”校验。
- ackend/app/services/asr_service.py
  - ASR 输出路径改为按条目目录保存，文件名规则：<条目名>.srt（自动做非法字符清洗）。
- ackend/app/schemas/source_video.py
  - 响应结构增加 has_uploaded_srt。
