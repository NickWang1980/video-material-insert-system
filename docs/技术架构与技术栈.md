# 技术架构与技术栈

## 后端
- Python 3.11+
- FastAPI
- SQLite（SQLAlchemy 2.x）
- FFmpeg / ffprobe（视频与音轨处理）
- pysrt（SRT 解析）
- faster-whisper（本地 ASR 生成 SRT）
- openpyxl（报告导出 xlsx）
- loguru（日志）

## 前端
- Vue 3 + Vite
- Element Plus（基础组件）
- Tailwind CSS 3.x
- Pinia（状态管理）
- Axios（API 调用）

## 架构要点
- 源视频条目与任务分离：先管理源视频，再创建任务。
- 字幕双来源：上传 SRT 与 ASR SRT 并行存在，可按任务选择。
- ASR 异步后台执行：不阻塞条目创建。
- API 固定前缀：`/api`；生产态由后端托管 `frontend/dist`。
