# 模板素材下拉联动与悬停预览

- 时间：2026-04-20 22:32:09
- 目标：新建/编辑模板中，“素材文件名”改为下拉选择，并根据“素材类型”联动；悬停文件名可预览素材。

## 已实现
- `frontend/src/views/ConfigEditor.vue`
  - 素材配置列改为：左侧 `素材类型` 下拉，右侧 `素材文件名` 下拉。
  - 文件名下拉按素材类型联动加载：
    - 图片 → `file_type=image`
    - GIF → `file_type=gif`
    - 短视频 → `file_type=video`
  - 悬停素材文件名选项时显示实时预览（图片/GIF 显示图像，短视频自动静音循环预览）。
  - 切换素材类型后自动校验已选文件名，不匹配则清空，避免脏配置。
  - 保留“提示音”下拉与试听能力。

## 说明
- 本次无后端接口变更，复用现有 `GET /api/materials?file_type=...` 与 `GET /api/materials/{id}/preview`。
- README 已补充该交互说明。
