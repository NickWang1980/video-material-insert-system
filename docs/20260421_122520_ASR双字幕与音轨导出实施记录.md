# ASR双字幕与音轨导出实施记录

- 时间：2026-04-21 12:25:20
- 范围：源视频音轨导出（wav/flac）+ 双SRT（上传SRT/ASR SRT）+ 任务字幕来源切换 + UI与文档同步

## 已完成改动
- 源视频条目模型新增音轨与ASR相关字段，任务新增 `subtitle_source`，设置新增 `asr_model`。
- SQLite 兼容迁移已补齐新增列（老库自动升级）。
- 源视频创建流程改为：上传视频/SRT → 导出 wav/flac → 解析上传SRT → 异步ASR。
- 新增接口：
  - `GET /api/source-videos/{id}/audio?format=wav|flac`
  - `GET /api/source-videos/{id}/subtitle?source=uploaded|asr`
  - `GET /api/source-videos/{id}/subtitle/parsed?source=uploaded|asr`
- 任务创建新增 `subtitle_source`（默认 `uploaded`），`asr` 仅在状态完成时可用。
- 前端源视频库新增音轨下载、ASR状态、失败原因、双SRT识别预览。
- 新建任务弹窗新增字幕来源下拉，ASR未完成时禁用。
- 系统设置新增 ASR 模型选择（small/medium）。
