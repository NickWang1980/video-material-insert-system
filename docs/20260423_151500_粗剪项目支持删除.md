# 变更记录：混剪项目支持删除

## 变更目标
- 在多角色混剪“项目与文案”区域支持删除当前项目。

## 后端变更
- 新增 `DELETE /api/rough-cut/projects/{project_id}`。
- 删除项目时同步清理：
  - 项目素材文件
  - 角色素材 ASR SRT
  - 预览与导出文件
  - `data/uploads/rough_cut_assets/project_{id}`
  - `data/uploads/rough_cut_subtitles/project_{id}`

## 前端变更
- `frontend/src/api/roughCut.js` 新增 `deleteRoughCutProject`。
- `RoughCutMultiRole.vue` 在项目选择区新增删除按钮。
- 删除确认后刷新项目列表；若仍有项目则自动切换到下一个，否则清空当前工作区。

## 文档同步
- 更新 `docs/API接口文档.md` 的混剪项目接口说明。
