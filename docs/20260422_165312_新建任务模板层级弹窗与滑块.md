# 变更记录：新建任务模板层级弹窗与滑块

时间：2026-04-22 16:53:12

## 变更内容
- 在“新建剪辑任务”弹窗中，模板区域新增“设置层级”入口。
- 点击后弹出层级设置对话框，可对每个已选模板通过滑块拖动设置层级（1~100）。
- 层级值越大优先级越高，界面展示“当前层级顺序（高→低）”。
- 任务创建、冲突校验、近距冲突预检均按层级排序后的模板顺序提交。

## 影响文件
- `frontend/src/components/task/CreateTaskModal.vue`

## 兼容性
- 后端接口不变，仍使用 `config_ids[]`；前端仅调整传参顺序。
