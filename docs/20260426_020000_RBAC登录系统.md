# RBAC + 登录页面

## 改动摘要

为系统添加 JWT 认证 + 角色权限控制（RBAC），新增登录页面，内置两个初始用户。

## 涉及文件

### 新增（后端）
| 文件 | 说明 |
|------|------|
| `backend/app/models/user.py` | User ORM 模型（users 表） |
| `backend/app/schemas/auth.py` | 登录请求/响应 schema |
| `backend/app/services/auth_service.py` | bcrypt 密码哈希 + PyJWT 令牌生成/验证 |
| `backend/app/api/auth.py` | `POST /api/auth/login`、`GET /api/auth/me` |
| `backend/app/middleware/auth_middleware.py` | JWT 验证中间件 + RBAC 写保护 |

### 新增（前端）
| 文件 | 说明 |
|------|------|
| `frontend/src/api/auth.js` | 登录/我的信息 API 封装 |
| `frontend/src/store/modules/auth.js` | Pinia auth store（token + user 持久化到 localStorage） |
| `frontend/src/views/Login.vue` | 登录页（Pexels 渐变背景 + 毛玻璃卡片） |

### 修改
| 文件 | 改动 |
|------|------|
| `backend/requirements.txt` | 新增 `PyJWT>=2.8.0`、`passlib[bcrypt]>=1.7.4` |
| `backend/app/config.py` | 新增 `jwt_secret` 配置 |
| `backend/app/models/database.py` | users 表迁移 + 内置用户 seed |
| `backend/main.py` | 注册 `AuthMiddleware`（最外层）和 `auth_router` |
| `backend/.env.example` | 添加 `JWT_SECRET` 说明 |
| `frontend/src/api/index.js` | 请求拦截器注入 Bearer token + X-Operator；响应拦截器处理 401 跳转登录 |
| `frontend/src/router/index.js` | 添加 `/login` 路由 + `beforeEach` 全局守卫 |
| `frontend/src/components/layout/Header.vue` | 显示当前用户名/角色 + 登出按钮 |
| `frontend/src/App.vue` | 登录页不渲染侧边栏和 Header |

## 初始用户

| 用户名 | 密码 | 角色 | 权限 |
|--------|------|------|------|
| admin | admin20260! | admin | 读写全部操作 |
| user | user123 | user | 只读（GET 请求），写操作返回 403 |

## RBAC 规则

- **admin**：所有 HTTP 方法均允许
- **user**：POST / PUT / PATCH / DELETE 全部返回 `403 权限不足`
- **公开接口**：`POST /api/auth/login`（无需 token）

## JWT 配置

- 算法：HS256
- 有效期：24 小时
- 密钥：`.env` 中 `JWT_SECRET`（默认值仅用于开发，**生产必须替换**）

## 是否需要重启/build

- **后端**：需要重启，并先执行 `pip install -r backend/requirements.txt`
- **前端**：dev 模式热更新自动生效；prod 需重新 build
