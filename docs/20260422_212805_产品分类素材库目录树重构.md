# 产品分类素材库目录树重构实施记录

## 完成目标
- 素材库从筛选模式升级为目录树模式。
- 目录层级固定为：产品目录 -> 脚本子文件夹。
- 模板规则新增目录上下文，支持同名素材按目录精确绑定。

## 后端改动
- 新增目录元数据表：`material_products`、`material_script_folders`。
- `materials` 增加 `product_id`、`script_folder_id`，并保留兼容字段 `product_name`、`script_folder`。
- 启动迁移支持：
  - 自动补列
  - 回填产品/子文件夹关系
  - 预置产品目录：`豆包`、`抖音精选`、`红果app`
  - 材料表唯一性迁移为目录作用域（定量素材全局、产品素材子文件夹内）
- 新增目录管理 API：
  - `GET /api/materials/tree`
  - `POST/PUT/DELETE /api/materials/products/*`
  - `POST/PUT/DELETE /api/materials/scripts/*`
- 上传接口改为按目录落盘：`library_kind + script_folder_id`。

## 前端改动
- 素材库页面改为左右布局：
  - 左侧目录树（定量素材、产品目录、脚本子文件夹）
  - 右侧素材视图（预览/详细）
- 目录节点支持新建、重命名、删除。
- 上传仅允许在“定量素材”或“脚本子文件夹”节点执行。
- 模板编辑页新增目录字段：
  - `素材库分类`
  - `产品目录`
  - `脚本子文件夹`
- 素材下拉改为按“目录 + 素材类型”过滤。

## CSV与匹配链路
- CSV 导入导出新增目录字段三列。
- 旧 CSV 缺失目录字段时默认按 `定量素材` 处理。
- 匹配服务改为按目录上下文定位素材，避免同名误匹配。

## 兼容性说明
- 旧模板可继续使用，默认走 `定量素材`。
- 旧素材数据会在启动迁移时自动回填到目录结构。
