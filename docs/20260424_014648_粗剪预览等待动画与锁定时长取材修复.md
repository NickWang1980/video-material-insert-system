# 混剪预览等待动画与锁定时长取材修复

## 变更时间
- 2026-04-24 01:46:48

## 变更目标
- 点击“一键混剪”或“重新生成”后，预览播放器显示可见的等待状态（三点呼吸动画）。
- 当句子已手动锁定时长并命中 ASR 时，按 ASR 起始时间截取“锁定时长”而不是 ASR 片段原始长度。

## 主要调整
- 预览播放器容器新增等待遮罩层，显示三点呼吸动画与“预览生成中”提示。
- 增加 `previewWaiting` 计算状态：一键混剪、重新生成、后端 processing 时均显示等待层。
- 后端 `build_timeline` 在 ASR 命中分支新增锁定时长策略：
  - `locked=true`：`sourceStart = ASR匹配起点`，`sourceEnd = sourceStart + lockedDuration`（超出素材长度时自动截断）。
  - `locked=false`：继续使用 ASR 匹配窗口原始结束时间。

- `frontend/src/views/RoughCutMultiRole.vue`
- `backend/app/services/rough_cut_service.py`
