# 单句分镜独立预览功能

**日期：** 2026-04-24  
**分支：** feature/multi-roles-cut  
**涉及文件：**
- `backend/app/services/rough_cut_service.py`
- `backend/app/api/rough_cut.py`
- `frontend/src/api/roughCut.js`
- `frontend/src/views/RoughCutUnit.vue`

---

## 功能说明

在混剪单元（RoughCutUnit）的每个分镜卡片中新增"预览本句"按钮，点击后调用 FFmpeg 同步渲染该句对应的取材片段（sourceStart ~ sourceEnd），渲染完成后在卡片内直接播放预览视频。

---

## 改动详情

### 1. `rough_cut_service.py` — 新增 `render_sentence_preview`

- 根据 `sentence_id` 在 `sentences_json` 中找到句子，再通过 `clipId` 在 `timeline_json` 中定位对应 clip
- 读取 clip 的 `sourceStart`、`sourceEnd`、`filePath`
- 读取项目渲染设置（分辨率、帧率、音频模式），构造与 `_render_timeline` 一致的 FFmpeg 命令
- 使用 `-preset ultrafast -crf 28` 加速渲染（单句预览，质量略降可接受）
- 输出路径：`data/outputs/rough_cut/sentence_previews/project_{id}/{sentence_id}.mp4`（覆盖写入，不累积临时文件）

### 2. `rough_cut.py` — 新增两个端点

| 端点 | 说明 |
|------|------|
| `POST /api/rough-cut/projects/{id}/sentence-preview/{sentenceId}` | 同步渲染单句预览，完成后返回 `{"ok": true}` |
| `GET /api/rough-cut/projects/{id}/sentence-preview/{sentenceId}/media` | 以 FileResponse 返回渲染好的 mp4 文件 |

### 3. `roughCut.js` — 新增两个 API 函数

- `previewRoughCutSentence(projectId, sentenceId)` — POST 触发渲染
- `getSentencePreviewUrl(projectId, sentenceId)` — 构造 GET 媒体 URL（加 `?t=timestamp` 防缓存）

### 4. `RoughCutUnit.vue` — 视图更新

- 新增 `sentencePreviewLoading` / `sentencePreviewUrls` 响应式对象
- 新增 `previewSentence(sentence)` 异步函数：调用渲染 API → 存储带时间戳的媒体 URL
- 新增"预览本句"按钮（仅当 clip 存在时可点击）
- 渲染完成后在卡片底部显示 `<video>` 播放器（max-height: 280px）

---

## 数据流

```
点击「预览本句」
  → POST /api/rough-cut/projects/{id}/sentence-preview/{sentenceId}
  → 后端 render_sentence_preview() 同步 FFmpeg 渲染
      ffmpeg -ss {start} -to {end} -i {filePath} -preset ultrafast ...
      → data/outputs/rough_cut/sentence_previews/project_{id}/{sentenceId}.mp4
  → 返回 {"ok": true}
  → 前端设置 sentencePreviewUrls[sentenceId] = /api/.../media?t=xxx
  → <video :src="..."> 自动加载播放
```
