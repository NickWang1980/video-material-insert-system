# 2026-04-22 变更记录：ASR 简体输出与 5×5 九宫格映射

## 目标
- 自动生成字幕（ASR）统一输出简体中文。
- 九宫格改为 5×5 参考网格展示，但实际定位仍使用 1-9 九宫格编号。

## 实施内容
- `backend/app/services/asr_service.py`
  - `faster-whisper` 转写时固定 `language="zh"`。
  - 新增 `OpenCC(t2s)` 转换，确保写入 SRT 的文本为简体中文。
  - 缺少简体转换依赖时抛出明确错误，避免生成非简体结果。
- `backend/requirements.txt`
  - 新增 `opencc-python-reimplemented>=0.1.7`。
- `backend/app/services/video_service.py`
  - 九宫格坐标从贴边系数改为 5×5 红色中心区映射：
    - 原 `x/y` 系数：`0 / 0.5 / 1`
    - 现 `x/y` 系数：`0.25 / 0.5 / 0.75`
- `frontend/src/components/common/GridSelector.vue`
  - 组件改为 5×5 参考网格 UI。
  - 仅中间 3×3（红色区域）可选，并映射到九宫格位置 1-9。

## 兼容性说明
- 模板与接口中的 `九宫格位置` 仍保持 1-9，不改字段定义。
- 旧任务与旧模板无需迁移即可继续运行。
