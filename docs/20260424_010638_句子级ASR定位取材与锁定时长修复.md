# 句子级ASR定位取材与锁定时长修复

## 变更时间
- 2026-04-24 01:06:38

## 本次目标
- 混剪时间线改为按剧本文案逐句匹配角色视频 ASR 片段窗口取材。
- 修复一键混剪、重新生成、生成时间线时已锁定句子秒数被重置的问题。
- 返回并展示角色素材资产级 ASR 起止时间与总时长。

## 核心调整
- 后端把单条 segment 匹配改为连续 ASR 片段窗口匹配，按句子文本选择起始时间和结束时间。
- 命中 ASR 时，混剪 clip 的实际取材区间由 ASR 匹配窗口决定。
- 已锁定句子的 `estimatedDuration` 不再被系统自动回写覆盖。
- 前端不再在一键混剪、重新生成、生成时间线时隐式执行“自动拆句”。
- 角色素材卡片与 ASR 对比中心新增 `ASR时长` 展示。

## 影响范围
- `backend/app/services/rough_cut_service.py`
- `backend/app/schemas/rough_cut.py`
- `frontend/src/views/RoughCutMultiRole.vue`

## 运行说明
- 本次改动涉及前后端。
- 需重启后端服务。
- 若使用生产端口 `8000`，需重新构建前端并重启后端。
