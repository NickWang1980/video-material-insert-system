# 锁定时长与预览刷新修复记录

- 时间：2026-04-24 07:53:55
- 范围：`frontend/src/views/RoughCutMultiRole.vue`、`frontend/src/views/RoughCutUnit.vue`、`backend/app/services/rough_cut_service.py`

## 本次修复
- 重新生成预览时，后端先删除旧预览文件，再写入新版本，避免目录中残留上一版预览。
- 旧版 `多角色混剪` 的一键粗剪不再隐式重新拆句；已有句子结构、锁定时长和手动编辑值会被保留。
- 两个粗剪页面在生成预览/粗剪前都会先把句子的 `estimatedDuration + locked` 同步到后端，锁定时长不再因为未保存而丢失。
- 当句子命中 ASR 时，如果用户手动锁定为更短时长，仍从命中的 ASR 起点开始，只截取锁定后的秒数。
- 预览区在“重新生成预览 / 一键粗剪 / 单句重生成”期间显示等待遮罩与三点呼吸动画。
- 预览视频地址增加版本戳并使用 `video key` 强制刷新，生成完成后会自动切换到最新版本。

## 影响说明
- 本次未改动接口路径。
- 生产模式如需在 `8000` 端口看到最新前端行为，需要重新 build 前端并重启后端。
