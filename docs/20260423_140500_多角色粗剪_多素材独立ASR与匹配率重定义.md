# 变更记录：多角色混剪多素材与独立ASR

## 本次目标
- 单角色支持上传多个视频素材并保留。
- 每个素材独立执行 ASR、独立生成 SRT、独立计算匹配率。
- 匹配率改为素材粒度：`matchedChars / srtTotalChars`，并新增 `unmatchedChars`、`errorPercent`。
- 一键混剪放行规则改为：所有素材 ASR 完成且每个素材匹配率 `>=95%`。

## 关键实现
- 后端混剪素材上传由“替换”改为“追加”；上传后对每个新增素材分别调度 ASR。
- 门槛判定改为素材粒度评估，角色汇总状态仅用于展示。
- 时间线选片改为“角色下跨素材 ASR 最优匹配 + 每素材片段游标不重复消费”，未命中时回退常规切片。
- 对比接口升级为项目/角色/素材三级数据结构，角色层补充 `roleSummary`，素材层返回独立统计与状态。
- 前端混剪页角色素材库改为多素材列表展示；对比弹窗改为项目→角色→素材三级分页。

## 兼容性
- 接口路径保持不变。
- `GET /api/rough-cut/projects/{id}/compare` 保留角色层原字段，同时新增素材明细字段，前端可渐进升级。
