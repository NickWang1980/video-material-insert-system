# 登录页白屏修复

**时间：** 2026-04-26 03:00  
**分支：** feature/multi-roles-cut

## 问题描述

访问登录页时只显示白屏，登录表单无法加载。

## 根本原因（4个）

### 1. 旧版 `frontend/dist/` 存在
旧构建（auth功能添加之前的版本）仍然存在于 `frontend/dist/`。后端 `main.py` 检测到 `dist/` 存在时会优先服务旧前端。旧前端没有登录页，且无法处理新 `AuthMiddleware` 返回的 401 响应，导致白屏。

### 2. `main.js` 未等待路由初始化
原代码在路由初始化完成之前就挂载 App。初始渲染时 `route.name === undefined`，`isLoginPage = false`，导致 app shell（白色背景）先于登录页渲染，产生白屏闪烁。

### 3. `users.js` 使用错误的 default import
```js
// 错误
import api from "./index";  // api 为 undefined（index.js 只有 named export）

// 正确
import { api } from "./index";
```
同时 URL 有重复前缀问题（baseURL 已是 `/api`，但 URL 写成 `/api/users`）。

### 4. `index.html` viewport 缩放比例错误
`initial-scale=2.0` 应为 `initial-scale=1.0`，移动端会被强制缩放至200%。

## 修复内容

| 文件 | 改动 |
|------|------|
| `frontend/dist/` | 删除旧版构建，防止后端服务过时前端 |
| `frontend/index.html` | 修复 `initial-scale=2.0→1.0`；添加 `#app:empty { background: #0a0a14 }` 防止挂载前白屏 |
| `frontend/src/main.js` | 改用 `router.isReady().then(() => app.mount())` 确保路由解析完成后再挂载，消除 app shell 白屏闪烁 |
| `frontend/src/api/users.js` | 修正 `import { api }` 且去掉重复 `/api` URL 前缀 |

## 涉及文件

- `frontend/index.html`
- `frontend/src/main.js`
- `frontend/src/api/users.js`
- `frontend/dist/` (已删除)

## 是否需要重启

**前端热更新自动生效**（Vite dev server 自动重载）。  
**后端无需重启**（仅前端代码变更）。
