# 混剪单元项目列表分页

## 改动摘要

为混剪单元（`/rough-cut/unit`）项目列表添加分页、每页条数选择，保持 CRUD 完整可用。

## 涉及文件

| 文件 | 改动 |
|------|------|
| `backend/app/schemas/rough_cut.py` | `ListProjectsResponse` 新增 `total: int = 0` |
| `backend/app/api/rough_cut.py` | `GET /projects` 增加 `page` / `page_size` 查询参数，返回分页结果与总数 |
| `frontend/src/api/roughCut.js` | `listRoughCutProjects(page, pageSize)` 传参并返回 `{items, total}` |
| `frontend/src/views/RoughCutUnit.vue` | 新增分页状态、`handleProjectPageChange`、`handleProjectPageSizeChange`；CRUD 操作后重置到第 1 页；模板加 `el-pagination` |

## 行为说明

- 默认每页 9 个（3×3 网格），可选 9 / 18 / 36
- 项目总数 ≤ 每页数时不显示分页栏
- 新建、删除、重命名后自动跳回第 1 页（保证最新项目可见）
- 翻页只刷新列表，不影响已加载的当前项目详情

## 是否需要重启/build

- **后端**：需要重启
- **前端**：热更新自动生效（dev 模式）；prod 模式需重新 build
