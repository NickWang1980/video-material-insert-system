# 20260423_112631 多角色混剪9项改造补齐

## 本次实现
- 混剪页面中栏重排：顶部进度条+百分比、75%预览播放器、50%高度时间线、句子列表下移到时间线下方。
- 时间线新增可拖动滑块，支持与播放器进度双向同步。
- 角色素材上传后自动触发 ASR（faster-whisper，简体中文转换）。
- 角色素材返回识别状态与匹配率字段，并在页面显示呼吸进度条和百分比。
- 新增匹配门槛：仅 >=95% 可执行一键混剪；<80% 弹窗强提示，80~95% 禁用放行。
- 时间线生成新增字幕对齐切分：优先用ASR段落时间作为片段起止，缺失时回退估时策略。
- 后端导出接口增加门槛校验，避免绕过前端直接启动混剪。
