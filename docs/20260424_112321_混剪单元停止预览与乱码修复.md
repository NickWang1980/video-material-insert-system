# 混剪单元停止预览与乱码修复

- 时间：2026-04-24 11:23:21
- 范围：`backend/app/services/rough_cut_service.py`、`backend/app/api/rough_cut.py`、`backend/app/schemas/rough_cut.py`、`frontend/src/api/roughCut.js`、`frontend/src/views/RoughCutUnit.vue`、`frontend/src/router/index.js`、`frontend/src/components/layout/Sidebar.vue`、`frontend/src/components/layout/Header.vue`

## 本次变更
- 为混剪单元新增“停止生成预览”能力，前端按钮对接后端停止接口。
- 后端粗剪导出链路增加停止请求、FFmpeg 进程终止、停止中/已停止阶段标记。
- 修复粗剪项目日志、状态文案、阶段文案的乱码问题，并对历史日志返回做兼容修复。
- 隐藏旧“多角色混剪”入口，并将旧路由重定向到 `混剪单元`。

## 说明
- 停止后项目会回到非 processing 状态，阶段显示为“已停止”。
- 重新发起生成预览/导出时，会自动清理上一次停止请求。
- 若通过 `8000` 生产口访问，需要重新构建前端并重启后端。
