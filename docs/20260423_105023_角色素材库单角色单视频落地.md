# 20260423_105023 角色素材库单角色单视频落地

## 本次变更
- 混剪素材接口收敛为上传/查看/删除三类能力，移除角色间移动接口。
- POST /api/rough-cut/projects/{project_id}/assets 改为同角色自动替换旧素材，确保每角色仅保留 1 条视频。
- 素材替换与删除后，统一清空时间线缓存与预览/导出路径，项目状态重置为 idle 并写入日志。
- 新增 GET /api/rough-cut/projects/{project_id}/assets/{asset_id}/media，用于角色素材预览。
- 混剪页面角色素材库改为“单槽位”展示：上传、预览、删除；去除角色移动交互。

## 兼容性
- 旧项目若同角色存在多条历史素材，前端按最新一条展示；重新上传后会收敛到单条。
- 任务/时间线/导出接口路径保持不变。

## 重启说明
- 后端接口已变更，需要重启后端服务。
- 前端页面与 API 已变更，需要重新构建或重启前端开发服务。
