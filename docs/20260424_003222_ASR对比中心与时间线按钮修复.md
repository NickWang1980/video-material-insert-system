# ASR对比中心与时间线按钮修复

## 变更时间
- 2026-04-24 00:32:22

## 变更目标
- 修复 ASR 匹配对比中心复用旧缓存导致识别文本为空的问题。
- 角色 A/B/C 素材选择或拖拽后自动上传，移除显式上传按钮。
- “生成时间线”按钮自动执行必要前置步骤，并在失败时显示明确中文提示。

## 主要调整
- 前端打开对比中心、切换项目、ASR 完成自动弹窗前强制刷新 compare 数据。
- 后端 compare 每个素材只解析一次 ASR SRT，文本与匹配统计来自同一份解析结果。
- 角色素材上传区选择/拖入视频后自动上传并启动字幕识别。
- 生成时间线流程调整为：确保项目存在 → 保存设置 → 拆句 → 分配角色 → 生成时间线。
- `/build-timeline` 缺少文案或素材时返回正常 UTF-8 中文错误。

## 影响范围
- 混剪页面：ASR 对比中心、角色素材库、生成时间线按钮。
- 后端混剪服务：compare payload 与时间线错误提示。

## 运行说明
- 本次改动涉及前端与后端。
- 本地开发需重启前端开发服务与后端服务。
- 生产端口 `8000` 需重新构建前端后重启后端服务。
