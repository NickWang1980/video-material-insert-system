# 2026-04-22 素材库分类与产品子文件夹支持

## 变更目标
- 素材库新增两级业务分类：`定量素材`、`产品分类素材`。
- 产品分类素材支持产品文件夹与子文件夹（脚本维度）管理。

## 后端变更
- `materials` 表新增字段：`library_kind`、`product_name`、`script_folder`。
- 启动迁移自动补齐以上字段，并将历史数据默认归类为 `general`。
- `POST /api/materials` 支持上传时携带分类元信息。
- `GET /api/materials` 支持按分类与文件夹筛选。
- 新增目录管理接口：
  - `GET /api/materials/folders`
  - `POST /api/materials/folders`
- 上传视频素材仍保留“自动去音轨”逻辑。

## 前端变更
- 素材库页新增分类选择：`定量素材` / `产品分类素材`。
- 在产品分类下新增：
  - 产品文件夹选择/创建
  - 子文件夹选择/创建
- 上传动作按当前分类与文件夹写入后端。
- 列表增加“素材分组”显示，便于识别来源。

## 兼容性
- 历史素材记录可继续使用；未分组素材默认视为 `定量素材`。
- 原有 `file_type` 筛选与预览、重命名、删除功能保持可用。
