# 短视频智能素材自动植入工具 V1.0（项目开发文档）

## 核心定义（本版）
- 输出目标：成品视频 + 执行报告（xlsx）+ 处理日志（txt）。
- 字幕来源：支持两路  
  1) 用户上传 SRT（默认）  
  2) ASR 生成 SRT（faster-whisper，本地离线）
- 源视频条目创建后自动完成：
  - 视频元数据识别（分辨率/比例）
  - 音轨导出（wav/flac）
  - ASR 后台生成字幕（异步，不阻塞创建响应）

## 关键流程
1. 上传素材（图片/GIF/短视频/音效）。
2. 创建模板（关键词、素材、提示音等）。
3. 创建源视频条目（视频 + SRT）。
4. 系统导出音轨并后台生成 ASR SRT。
5. 创建任务（源视频条目 + 多模板 + 字幕来源）。
6. 处理完成后下载成品视频、报告、日志。

## 字幕策略
- `uploaded`：直接使用条目上传的 SRT。
- `asr`：按“ASR SRT 文件存在优先”可选；若文件不存在，再根据 `asr_status` 判断是否未就绪。
- 默认：任务创建使用 `uploaded`。

## 任务状态与兼容
- 状态：`pending / processing / stopped / completed / failed`。
- 历史任务兼容：未设置 `subtitle_source` 时按 `uploaded` 处理。
- 删除任务：仅清理任务产物，不清理源视频条目文件。
- 任务执行稳定性：
  - 修复 FFmpeg 进程日志管道阻塞导致的“进度卡在 75%”问题。
  - 新增编码阶段进度心跳（75%→98%）和超时保护，异常可自动失败回退。

## ASR 说明
- 引擎：`faster-whisper`
- 模型：`small|medium`（系统设置可选，默认 `small`）
- 语言：自动识别
- 失败处理：标记 `asr_status=failed` 并记录 `asr_error`，不影响 `uploaded` 流程可用性。
- 新增循环递推重试：识别失败自动重试（默认上限 3 次），并记录重试计数。
- 服务启动会自动续跑可恢复的 ASR 条目（`pending/running` 与可重试 `failed`）。

## 2026-04-21 规则补充（源视频条目）
- 新建源视频条目时，`SRT` 非必填。
- 用户未上传 `SRT` 时，前端需弹框提示“将开始模型识别字幕”。
- ASR 生成字幕文件名与源视频条目名一致：`<条目名>.srt`。
- 任务默认字幕来源仍为 `uploaded`；若条目无上传字幕，在检测到 ASR SRT 文件可用后即可选择 `asr` 来源。
