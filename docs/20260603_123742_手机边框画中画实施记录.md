# 手机边框画中画 实施记录

> 时间：2026-06-03 12:37:42 ｜ 分支：feature/5.0 ｜ 作者：Nicholas + Claude

## 追加（2026-06-04）：修复素材轻微溢出手机范围

**现象**：素材装进手机屏幕后，仔细看会 slightly 越过屏幕、从黑边框下露出来一圈。

**根因**：`_feathered_alpha` 把「要抠除区」整体 `MaxFilter` 膨胀 2px，而抠除区**同时包含屏幕**。膨胀屏幕抠除区＝把透明孔向外撑大 2px、越过黑边框内沿，素材(填在屏幕 bbox 里)便从被撑开的孔里露到边框上。这个膨胀本意只为吃掉**背景**外侧的抗锯齿灰毛边。

**修复**：把背景与屏幕的羽化拆开——背景去除区仍向外膨胀 2px(吃灰边)，屏幕透明孔**不膨胀**(`_feather_remove(screen_remove, 0, feather)`)，孔沿恰好停在黑边框内沿。注意不能改用「向内腐蚀」缩孔：腐蚀会露出原屏幕色(白)的一圈不透明环。新增 `cache_version=2`，旧 `.rect.json` 失配自动重算，既有边框无需重传即生效。回归测试 `test_screen_hole_does_not_bulge_into_bezel`。

## 追加（13:xx）：去纯色背景 + 上传管理迁到设置页 + 图片自动滚动

1. **上传/抠图迁到「设置」页**：`Settings.vue` 新增「手机边框管理」区块（上传+列表+预览+删除，`DELETE /api/phone-frames/{name}`）；`ConfigEditor` 只保留下拉选择。上传一次反复复用。
2. **去纯色背景 + 只留边框**：`phone_frame_utils.detect_screen_rect` 改为**全分辨率 PIL flood fill**（RGBA 感知）——从四角去背景、从中心抠屏幕，黑边框因色差/alpha 差被保留；即使背景与屏幕同色（仅靠黑边框隔开）也能分别去掉。守卫：若去背景会抹掉手机本体（剩余不透明 < 0.5%）则放弃去背景。产出 `{stem}.cut.png` 供叠加。
3. **图片素材自动竖向滚动**：`video_service` 手机边框分支，若素材是**图片**且按屏幕宽铺满后比屏幕高 → `scale=宽:全高, crop=宽:屏高:0:((IH-屏高)*min(t/dur,1)), pad` 做长截图滚动；**视频素材不滚动**（cover 裁切）。
4. 已在用户真实边框 `water_147095_698_698_.png`（灰底+黑边框+同色屏幕）上实测：背景与屏幕透明、仅留黑边框（含灵动岛/侧键）；滚动 filtergraph 经真实 ffmpeg 跑通。

## 追加（14:xx）：按百分比相对源视频缩放

之前用整张边框图（含原图透明边距）适配画布，手机本体偏小、受原图尺寸限制。改为：`detect_screen_rect` 返回 `content_bbox`（去背景后剩余不透明边框的外接框=手机本体），`video_service` 缩放改为 `s = min(画布宽/本体宽, 画布高/本体高) × (百分比/100)`。于是 100% = 手机本体铺满源视频（占满绑定边），75% = 占 3/4，不再受原图边距影响。实测 1080×1920 上：100%→手机 935×1920（满高），75%→701×1440。

## 追加（15:xx）：去背景毛边修复

硬切只删接近背景/屏幕色的像素，黑边框外残留一圈抗锯齿浅灰=毛边。`phone_frame_utils._feathered_alpha`：先 `MaxFilter` 把抠除区向边框内膨胀 2px（吃掉灰边、边界落进纯黑边框），再 `GaussianBlur(1.0)` 羽化成平滑抗锯齿，用 0~1 遮罩乘原 alpha（羽化带在纯黑边框上，半透明也是黑色，无灰晕）。真实边框边界灰毛边像素数下降 ~66%，红底合成肉眼为干净黑边框。

## 一、需求背景

承接已上线的「圆角画中画」。给被插入的素材视频套一个**仿手机外壳**——四周圆角黑边框 + 顶部 iOS 状态栏（时间/信号/WiFi/电量/5G），让 PiP 看起来像"在一部手机屏幕里播放的内容"。

产品决策（已与用户确认）：
- **边框来源**：用户**上传 PNG**（中间屏幕区透明、边框/状态栏已烤进图片）。不程序生成、不内置预设。
- **视频适配**：**填满并裁切（cover）**。
- **状态栏**：固定（来自用户上传的 PNG）。

做成「画中画类型」的第三个选项：`普通 / 圆角 / 手机边框`，复用现有 `build_ffmpeg_command()` 与圆角已建好的「额外 PNG 输入 + opacity 尾链」机制。

## 二、技术方案

### 屏幕透明区自动识别
上传时用 Pillow+numpy 从 alpha 通道识别"屏幕透明洞"：
1. `transparent = alpha < 16`。
2. 从图片四边对透明像素 flood fill，标记「外部透明」（手机轮廓外的背景）。
3. 剩余「内部透明区」= 屏幕；取 bounding box `(x,y,w,h)`。
4. 无内部透明区 → 兜底用整框内缩 6% 作屏幕区（log 警告）。
5. 结果 + `frame_w/frame_h` 写同名 `.json` sidecar 缓存。

工具：`backend/app/utils/phone_frame_utils.py::detect_screen_rect(png_path)`（下采样到 ≤480px 加速 flood fill）。

### FFmpeg 合成（手机边框分支）
整框按 size_ratio 适配画布 → `ow,oh`；屏幕区等比缩放 → `rx,ry,rw,rh`：
```
[frameIdx:v] scale=ow:oh [frm]
[matIdx:v] (trim/setpts) format=rgba,
  scale=rw:rh:force_original_aspect_ratio=increase, crop=rw:rh,   # cover 裁切
  pad=ow:oh:rx:ry:color=black@0 [vp]                              # 放屏幕位置(透明底)
[vp][frm] overlay=0:0:shortest=1 [framed]
[framed] trim=duration, setpts...+start/TB, colorchannelmixer=aa=opacity [ov]
```
边框 PNG 作额外 `-i -loop 1` 输入，复用 `mask_to_index`（索引排在 materials+音效之后）。边框缺失 → 回退「普通」。
