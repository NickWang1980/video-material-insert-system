# 任务多模板合并更新记录

- 时间：2026-04-20 17:51:40
- 范围：任务创建流程从“单模板/CSV”切换为“多模板合并”

## 已落地项
- 后端 `POST /api/tasks` 入参调整为 `config_ids[]`
- 创建任务时执行模板合并与关键词冲突校验
- 冲突时返回 `400`，并携带冲突关键词与模板名列表
- 新增任务快照字段 `source_templates_json`，记录任务创建时模板来源
- `GET /api/tasks`、`GET /api/tasks/{id}` 返回 `source_templates`
- 前端新建任务弹窗改为多模板选择，移除任务创建 CSV 上传入口
- 前端新增冲突预检，冲突时禁用提交并展示可读冲突列表
- 任务详情页新增“使用模板”展示
- 文档同步更新：`README.md`、`docs/API接口文档.md`、`docs/部署指南.md`

## 兼容说明
- 兼容保留 `tasks.config_id`（历史数据可读）
- 历史任务若无模板来源快照，`source_templates` 返回空数组
- 模板 CSV 导入/导出能力保留在“配置模板”模块
