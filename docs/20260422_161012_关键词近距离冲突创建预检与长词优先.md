# 变更记录：关键词“近距离冲突”创建预检 + 运行时长词优先

时间：2026-04-22 16:10:12  
范围：后端任务创建/匹配链路、任务接口、任务创建弹窗、任务详情展示、测试与文档

## 目标
- 支持 `快乐老家`、`快乐`、`老家` 同时配置。
- 在创建任务时基于完整 SRT 给出冲突强警告。
- 运行时避免同一字幕行重复触发，按“长词优先”执行。

## 后端变更
- `task_config_snapshots` 新增 `keyword_collision_warnings_json`（含 SQLite 兼容迁移）。
- 新增任务创建预检能力：
  - `build_keyword_collision_warnings_for_task(...)`
  - `detect_keyword_collision_warnings(...)`
- 新增接口：
  - `POST /api/tasks/keyword-collision-check`
- `POST /api/tasks` 返回 `keyword_collision_warnings`。
- `GET /api/tasks`、`GET /api/tasks/{id}` 返回 `keyword_collision_warnings` 快照。
- 运行时去重策略落地到匹配阶段：
  - 同一字幕行命中多个关键词时，仅保留 winner。
  - winner 规则：关键词长度优先；同长度按模板合并顺序优先。
  - 被抑制项记录失败原因：`被长词覆盖: {winner}`。
- 修复：任务运行中解析 ASR 字幕时强制 `utf-8` 编码，避免按上传字幕编码误解析。

## 前端变更
- 新建任务弹窗新增“近距离冲突强警告”展示区。
- 在已选源视频条目 + 模板组合后自动调用预检接口。
- 冲突不阻止创建；仅对“同名关键词冲突”继续阻止。
- 任务详情页显示创建时冲突预警快照。
- 任务创建成功提示支持显示“已按长词优先处理”的预警信息。

## 兼容性
- 保留原有“跨模板同名关键词冲突 = 400 阻止创建”规则。
- 历史任务若无快照字段，接口返回 `keyword_collision_warnings=[]`。
- 任务处理主流程（解析/合成/报告/下载）保持兼容。
