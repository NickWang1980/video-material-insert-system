# 变更记录：混剪句子时长移除 8 秒上限

## 变更目标
- 句子列表不再限制单句最长 8 秒。
- 混剪时间线中每段时长以匹配到的角色视频 ASR 片段真实长度为准。

## 后端变更
- `build_timeline` 移除 `required` 的 8 秒上限，只保留最小时长保护。
- ASR 命中时，`duration = sourceEnd - sourceStart`，不再截断到 8 秒。
- 生成时间线后继续把真实片段时长写回 `sentence.estimatedDuration`。

## 前端变更
- 句子列表的时长输入框移除 `:max="8"`。
- 用户可手动设置超过 8 秒的 fallback 时长。

## 行为说明
- ASR 匹配成功时，时间线片段长度等于角色视频中该句台词的实际讲话长度。
- ASR 未匹配成功时，仍使用估算或手动时长作为 fallback，并沿用现有素材轮播逻辑。
